# Project context

For Perfection by Riri work, consult the owner’s private `PROJECT_CONTEXT.md` before making changes. Authorized contributors can locate it in the owner’s GitHub repositories. After approved changes, prepare the relevant update in that document as part of the same task. Keep private project details in the private repository.

If the required project context is unavailable in this session, stop and tell the owner. Do not continue from memory.

# Working rules

- If the task is unambiguous, start right away and restate your understanding briefly in the same reply. Ask before starting only when the request is genuinely ambiguous or a mistake would mean expensive rework.
- "Done" means evidence (command and output, or a CI run ID) plus an explicit list of what was not verified. Use the four sections of `.github/pull_request_template.md`.
