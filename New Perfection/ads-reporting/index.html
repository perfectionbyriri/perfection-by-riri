Private salon advertising tool

Perfection BY RIRI - Ads reporting

This tool is operated by Perfection by Riri, a beauty salon in Lynnwood, Washington. It helps the salon owner and the salon’s advertising specialist review and manage the salon’s own Google Ads account.

What the tool does

  • Reviews campaign settings, advertising costs, clicks and reported conversions.
  • Researches potential keywords, search demand and estimated advertising costs through Google Keyword Planner when API access is available.
  • Uses search-term reports to prepare keyword and negative-keyword recommendations.
  • Prepares proposed advertising changes for human review. The separate management connection can apply supported changes only after explicit human confirmation of the exact proposal.

Who can use it

The tool is used only by the salon owner and the salon’s advertising specialist. This page describes that private tool; it does not offer public registration or a client booking service.

Google authorization and processing

Authorized operators connect using Google authorization. The workflow uses a locally installed Google Ads MCP server and OpenAI Codex to request and analyze advertising data. Google Ads authorization permits account management; the available MCP tools and human confirmation steps limit how that access is used.

Keyword forecasts are estimates. A reported advertising conversion is not by itself proof of a completed payment, a first-time client or a completed salon visit.
